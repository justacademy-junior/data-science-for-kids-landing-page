# Data Science for Kids: Turning Numbers into Stories

A playful, responsive landing page that shows parents and children how data science turns numbers into stories. It has an interactive class vote lab, a four step data story guide, and clickable cards that lead to a free demo, kids programs, a full blog guide and a career path preview.

## Live page

Once GitHub Pages is on, your page will be at `https://YOUR-USERNAME.github.io/data-science-for-kids-landing-page/`.

## What is inside

The page is one self contained file, `index.html`, with no build step.

It includes a sticky header, an interactive bar chart where every tap adds a vote and rewrites the story, four step cards, four clickable link cards, a bold enroll section and a footer with quick links.

## How to publish on GitHub Pages

1. Create a new public repository named `data-science-for-kids-landing-page`.
2. Upload `index.html` and `README.md` to the main branch.
3. Open Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and the `/ (root)` folder, then save.
5. Wait about a minute and open your live link.

## Features

Mobile first responsive layout, keyboard friendly focus styles, reduced motion support, semantic HTML, a meta description for search engines and no external scripts.

## Customise

Change the fruits in the `fruits` and `emoji` arrays inside the script to make a new vote topic. Edit the colours in the `:root` block at the top of the stylesheet.
